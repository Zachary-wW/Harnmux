# Harnmux collaboration

Harnmux coordinates native harness members for conversations, research, writing and code work.

## Language

**Entry**: The place where the user talks to the team. It may use a different harness from the Leader.

**Leader**: The member responsible for coordination and synthesis. This describes authority, not a planning specialty.

**Worker**: A member assigned a bounded contribution, such as research, planning, review or implementation.

**Duty**: What a member contributes, independently of its harness and coordination authority.

**Conversation task**: Discussion, research, writing or advice whose delivery can be an answer without repository changes.

**Code task**: Work whose delivery includes changes to an explicitly chosen source baseline.

**Shared context**: Information deliberately provided to the team, rather than an assumed copy of the Entry's private conversation.

**Delivery**: A member's versioned answer and evidence, including code changes when applicable.

**Input delivery**: An explicitly selected earlier delivery consumed by another member.

**Result report**: A notification that a member delivery is ready. Saving, starting delivery and native receipt are separate facts.

**Acceptance**: The user's decision about a specified delivery version. It does not mean reading, changing files or merging code.
