Harness Mix already provides digest review/apply, versioned verification reports and turn history.
Do not claim these primitives as Harnmux inventions. Separate Leader/user receipts are an explicit
Harnmux contract; source sampling does not prove competitor absence.

Use the existing SQLite service for sealed packets and receipts because task.result/delivery were
previously overwritten on continuation. Two tables preserve review history without adding an artifact
server, scheduler, event bus or runtime dependency. SHA-256 refers to exported JSON; do not attempt
continuous worktree attestation or infer verification from a model's report.

Retain the native SwiftUI menu-bar client and ui-ux-pro-max/HIG design system. Review fields use
semantic colors, selectable text, explicit notes, separate labels and no default authorization.
Native interaction/accessibility requires separate real GUI verification.
